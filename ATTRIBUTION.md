# Sources, licences and credits

Each release file holds only sources whose licences can be combined. Every record keeps its
source id and the source's own record id, so it can be traced back.

## emissions.json.br

| Source | Licence | Credit |
|---|---|---|
| ÖKOBAUDAT, Federal Ministry for Housing, Urban Development and Building (BMWSB), Germany | Free of charge per the publisher; exact terms to be confirmed | ÖKOBAUDAT (oekobaudat.de). Record id and version kept per value. |

Includes every ÖKOBAUDAT dataset with an A1-A3 global warming figure, including datasets built on
background databases. Each record carries its ILCD+EPD dataset type and an accuracy rank:
1 specific (one manufacturer's plant), 2 average, 3 representative, 4 generic, 5 template.

## Not included

Global Energy Monitor and Spatial Finance Initiative plant lists (download forms; to be added by
hand once their licences are read). Product EPD platforms (EC3, 2050 Materials, ECO Portal,
environdec, INIES, NMD, baubook) do not allow redistribution and are looked up live in the app.
ICE, ecoinvent direct, WorldClim and other restricted sources are never included.
